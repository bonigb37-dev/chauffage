# Bren-nholz: DE / FR / EN

La boutique utilise des URL distinctes `/de`, `/fr` et `/en`. Les chemins existants redirigent selon le choix manuel enregistré dans le cookie `bren_locale`, puis la langue principale du navigateur. Toute autre langue utilise l'allemand. Un lien explicitement préfixé conserve sa langue.

Le domaine de référence est https://www.brennholz-direk.de. Chaque page publique possède une URL canonique, des alternatives DE/FR/EN et x-default allemand. Le sitemap contient les trois versions. Les identifiants des produits, prix, stocks, commandes et données des avis ne sont pas traduits.

Les traductions révisées sont dans `translations/reviewed.tsv`, indexées par l'inventaire source figé `customer-inventory.json`. Les fragments complémentaires sont dans `additional.json`. Exécuter `node scripts/prepare-translations.cjs` pour générer les dictionnaires. Une variante Python est fournie; Python n'était pas disponible sur ce poste. Ne pas réordonner l'inventaire sans migrer les indices. Toute nouvelle description de produit doit recevoir une traduction révisée: aucun service de traduction automatique n'est appelé.

Le rendu React est traduit côté serveur et navigateur; les liens et la recherche suivent la langue choisie. Les avis des clients restent dans leur langue originale. Les paramètres d'authentification et permissions Supabase restent indépendants de la langue.

Les modèles d'e-mails Supabase sont configurés séparément dans son tableau de bord. Publier Vercel ne les remplace pas et ne corrige pas les identifiants SMTP. Conserver les URL de retour déjà autorisées pour la confirmation et la récupération du mot de passe.

Google Merchant Center et Google Ads sont des services séparés: adapter la langue et les URL des flux et annonces au marché cible, puis demander leur validation. Un déploiement du site ne garantit pas leur approbation ni un classement Google.

Vérification navigateur: `node scripts/verify-i18n-browser.cjs http://localhost:3002 --security`. Ne soumet aucun formulaire, commande, paiement ou e-mail réel. Un build isolé peut utiliser la variable `BREN_BUILD_DIR=.next-i18n-test` pour éviter de partager le dossier d'un serveur de développement ouvert.
